El sistema fue construido a partir de una base open-source con licencia MIT y posteriormente adaptado, ampliado y transformado para incorporar funcionalidades propias, entre ellas:

- Dashboard comercial personalizado.
- Gestión de productos.
- Gestión de clientes.
- Registro de ventas.
- Descuento automático de stock.
- Control de inventario.
- Reportes comerciales.
- Exportación CSV.
- Asistente IA en modo local.
- Preparación opcional para integración con Claude mediante Anthropic API.
